# 🍔 Food Ordering App

A simple and interactive food ordering web application built with **React** and **Vite**. The application allows users to browse food items, log in, manage their orders, apply discount codes, and complete the checkout process.

## 🚀 Features

- **User Authentication:** Login functionality to access the application.
- **Food Ordering:** Browse available food items and select your favorite meals.
- **Order Management:** Add multiple food items and adjust quantities.
- **Shopping Cart:** Review selected items and manage your order before checkout.
- **Discount Codes:** Apply promotional codes to receive discounts on orders.
- **Checkout & Payment:** Calculate the final order total and proceed through the payment process.
- **Responsive Design:** User-friendly interface adapted to different screen sizes.

## 🛠️ Technologies Used

- **React.js** – Building the user interface and reusable components.
- **Vite** – Fast development environment and build tool.
- **JavaScript (ES6+)** – Application logic and interactivity.
- **CSS3** – Custom styling and layout.
- **Bootstrap** – Responsive design and UI components.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_REPOSITORY
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.
